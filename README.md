# ajeethv27.github.io

Source of **[ajeethv27.github.io](https://ajeethv27.github.io)**, the portfolio website of Ajeeth Venkat Prasat, Embedded Systems Engineer (Freiburg, Germany).

A single static page with no build step or framework: `index.html` plus images in `assets/`. It supports light and dark themes, respects `prefers-reduced-motion` and is responsive down to phone width. The hero waveform is a live canvas rendering of a TENG-style heel-strike signal.

The full engineering portfolio is available as a PDF: [`Ajeeth_Venkat_Prasat_Engineering_Portfolio.pdf`](Ajeeth_Venkat_Prasat_Engineering_Portfolio.pdf).
